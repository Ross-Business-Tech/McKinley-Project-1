# Render (backend)

**Status: Blueprint ready (`render.yaml`); never deployed.**

- Build: `pip install uv && uv sync --frozen --no-dev` (reproducible from `backend/uv.lock`).
- Start: `alembic upgrade head` then `uvicorn app.main:app --host 0.0.0.0 --port $PORT` (one process).
- Health: `GET /api/health` → `status`, provider/model, `is_mock`, `app_env`, database kind, resident source.
- `APP_ENV=hosted`: the app **refuses to start** with wildcard/localhost/http CORS origins, a missing or short
  `STAFF_API_TOKEN`, `GATE_OVERRIDE_ENABLED=true` or no `DATABASE_URL`. Messages never print values.

| Variable | Value | Secret? |
| --- | --- | --- |
| `APP_ENV` | `hosted` | no |
| `LLM_PROVIDER` / `GEMINI_MODEL` | `gemini` / `gemini-3.6-flash` (or `mock` + `LLM_MODEL=mock-deterministic-v1` until a key exists) | no |
| `GEMINI_API_KEY` | Google AI Studio key | **yes** (`sync: false`) |
| `DATABASE_URL` | Supabase Session pooler URI | **yes** |
| `CORS_ORIGINS` | exact Vercel address(es), `https://…` | no |
| `STAFF_API_TOKEN` | generated by Render | **yes** |
| `RESIDENT_DATA_SOURCE` | `database` (residents from the synthetic seed) | no |
| `SAFETY_CLASSIFIER` | `auto` (runs on Gemini; one extra call per turn) or `off` | no |
| `GATE_OVERRIDE_ENABLED` | `false` | no |

Limitations: the free plan sleeps (first request ≈1 minute); the in-memory lock means one instance only; staff and
evaluation routes stay closed to browsers (they need loopback or the `X-Staff-Token` header, which the website never
sends) — that is intentional until there is real staff sign-in; there is no customer authentication.
